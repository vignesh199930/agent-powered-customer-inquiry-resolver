# AI Usage

## Tools Used

I used ChatGPT as a development and learning assistant during this take-home assignment.

## How AI Was Used

AI assistance was used for:

- Understanding the assessment requirements
- Brainstorming the application architecture
- Getting guidance on the Express.js backend structure
- Getting guidance on frontend implementation
- Reviewing the agent workflow
- Improving project documentation

## Code Ownership and Understanding

All generated suggestions were reviewed, understood, tested, and adapted during the implementation of this project.

## AI in the Application

No external LLM, generative AI API, or AI service is used in the application.

The customer inquiry agent is implemented programmatically using:

- Keyword matching
- Conditional logic
- A predefined knowledge base
- Template-based response generation

This approach follows the assessment requirement that prohibits the use of external Large Language Models or complex AI services.
